# Ashwini Dubbewar — Portfolio

Personal portfolio site for Ashwini Dubbewar, AI Engineer (agentic AI, RAG, LLM evaluation).

Live site: https://YOUR-SITE.netlify.app

## What's inside

- `index.html` — the whole site (HTML, CSS and JavaScript in one file, no build step)
- `Ashwini_Dubbewar_Resume.pdf` — résumé linked from the "Download résumé" button

## Features

- **Ask my résumé:** a small in-browser retrieval demo that ranks résumé passages against a visitor's question and highlights matching terms
- **Skill evidence:** clicking a skill highlights where it was used in the experience section
- Light and dark themes, responsive layout, keyboard accessible, respects reduced motion

## Updating

Edit `index.html`, then commit and push. Netlify redeploys automatically from the `main` branch.

To update the résumé, replace the PDF with a new one using the same file name.
